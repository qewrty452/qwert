LANTERNS 2026 — Dark Green Launcher (Android 15)

Что это:
Исходный проект отдельного Android-лаунчера в приглушённой тёмно-зелёной палитре. Он показывает установленные приложения сеткой и открывает их по нажатию. Он не устанавливает и не меняет обои.

Важно:
- Это исходный проект, а НЕ готовый APK. APK не был собран или протестирован на nubia Neo 3 5G в этой среде.
- Лаунчер может менять только собственный домашний экран. Он не перекрашивает системную шторку, настройки, экран блокировки и интерфейс других приложений.
- Android может спросить, какой домашний экран использовать. Выбери LANTERNS 2026, чтобы проверить его; штатный лаунчер можно выбрать обратно в настройках приложений по умолчанию.
- APK, собранный как debug, подписывается тестовым ключом и предназначен для личной проверки. Для распространения нужен отдельный постоянный ключ подписи.

Как получить APK без Android Studio:
1. На GitHub создай новый репозиторий. Для простоты можно сделать его Private.
2. Загрузи в репозиторий ВСЕ файлы из этой папки, сохраняя структуру каталогов, включая скрытую папку .github/workflows.
3. Открой вкладку Actions и выбери workflow “Build LANTERNS 2026 APK”.
4. Нажми Run workflow и дождись зелёного статуса успешной сборки.
5. Открой завершённый запуск workflow. Внизу в Artifacts скачай “LANTERNS-2026-debug-apk.zip”. Распакуй архив — внутри будет app-debug.apk.
6. Перенеси APK на телефон и открой его для установки. Android может попросить разрешить установку из используемого файлового приложения. Разрешай это только для APK, который ты сам собрал из этого проекта.
7. После установки нажми Home и выбери LANTERNS 2026. Если Android не предложит выбор, открой настройки приложений по умолчанию и найди пункт «Главный экран / Home app».

Если workflow не появляется:
- Убедись, что файл лежит именно в .github/workflows/build-apk.yml.
- Сначала загрузи файлы в ветку main или master.
- В GitHub Actions может потребоваться включить Actions для репозитория.

Сборка использует GitHub Actions и скачивает Android Gradle Plugin/SDK из официальных репозиториев во время сборки. Интернет для облачной сборки необходим.
